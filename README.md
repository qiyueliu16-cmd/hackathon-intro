# hackathon-intro

黑客松组队自我介绍单页，托管于 GitHub Pages。

Live site: https://qiyueliu16-cmd.github.io/hackathon-intro/

## 分享给别人

- **推荐**：直接发在线链接，任何设备打开效果一致，且内容更新后对方刷新即可看到。
- **离线场景**：发 `hackathon-intro-standalone.html` 单文件（CSS/JS 已内联，微信/邮件传过去双击即可打开，无需联网），也可从线上地址下载：https://qiyueliu16-cmd.github.io/hackathon-intro/hackathon-intro-standalone.html

## Development

直接用浏览器打开 `index.html` 预览。改动 `index.html` / `styles.css` / `script.js` 后，如需单文件版可重新内联生成。

## Deployment

推送到 `main` 分支即自动部署（GitHub Actions → GitHub Pages）。
